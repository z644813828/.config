# image-fit

Предпросмотр PNG/JPEG/WebP/BMP/TIFF с увеличением на macOS, Yazi 26.9.1.
Использует встроенный `/usr/bin/sips`, установка зависимостей не нужна.

Создаёт отдельную PNG-копию в кэше до `preview.max_width × max_height`.
Yazi вписывает её в доступную панель с сохранением пропорций. Полосы при
несовпадении пропорций остаются; маленькие изображения могут быть размытыми.
Оригиналы не изменяются. EXIF-ориентация нормализуется перед увеличением.

Linux, недоступный кэш и ошибки конвертации используют стандартный preview.
Другие форматы, включая GIF и SVG, сохраняют стандартные обработчики.
Кэш сбрасывается через `ya cache clear`. После изменения конфигурации
перезапустить Yazi; очистка прежнего кэша для установки плагина не требуется.
