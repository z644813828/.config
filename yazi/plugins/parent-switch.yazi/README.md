# parent-switch.yazi

Ranger-style `move_parent` for Yazi 26.9.1.

- `]`: enter the next sibling of the current directory.
- `[`: enter the previous sibling.

For example, with `/base/2` as the current directory and `f` hovered, `]` enters
`/base/3`; Yazi then restores or chooses its normal hovered item.
