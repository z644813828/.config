# Changelog

Все заметные изменения Hex Editor.

## 1.0.9

- Удалён специальный перехват `Cmd+0`; сочетание снова обрабатывается глобальными
  правилами VS Code.

## 1.0.8

- Удалён специальный перехват `Alt+W`; переход между группами редакторов
  обрабатывается глобальным `keybindings.json`.

## 1.0.7

- `Alt+W` сделан глобальной командой перехода к следующей группе редакторов.

## 1.0.6

- Добавлена настройка `hexEditor.hoverOpacity` для прозрачности подсветки строки
  и столбца под указателем.

## 1.0.5

- Стрелки и Shift+стрелки работают через команды VS Code при активном Hex Editor,
  включая случай, когда webview ещё не получил фокус.

## 1.0.4

- `Ctrl+U` и `Ctrl+D` работают через команды VS Code без первого клика по ячейке.

## 1.0.3

- При открытии файла сетка редактора получает фокус для навигации с клавиатуры.

## 1.0.2

- Добавлены `Ctrl+U` и `Ctrl+D` как Page Up / Page Down.

## 1.0.1

- Добавлены специальные обработчики `Cmd+0` и `Alt+W` для webview.

## 1.0.0

- Пакет переименован в `hex-editor`.
- Идентификаторы расширения переименованы с `native*` в `hexEditor.*` и
  `local.hexEditor`.
- Внутренний футер перенесён в Status Bar VS Code.

## 0.2.0

- Offset, размер файла, выделение, тип группы, radix, поиск и навигация по
  совпадениям перенесены в Status Bar VS Code.
- Go to и Find используют штатные InputBox и Quick Pick VS Code.

## 0.1.19

- Счётчик выделения показывается только для двух и более байтов.
- Границы выделения перенесены в подсказку счётчика.

## 0.1.18

- Go to получил переключатель Hex/Dec с вводом адреса без `0x`.
- Размер файла прижат к правому краю футера.

## 0.1.17

- Подсветка строки и столбца при наведении зафиксирована на 6%.

## 0.1.16

- Убраны всплывающие подсказки у числовых и ASCII-ячеек.

## 0.1.15

- Подписи шестнадцатеричных колонок выровнены по центру.

## 0.1.14

- Временный регулятор прозрачности подсветки добавлен в футер.

## 0.1.13

- Убран статус Overwrite из футера.

## 0.1.12

- Наведение подсвечивает строку и столбец активной ячейки.
- Все совпадения поиска подсвечиваются; пустой запрос сбрасывает поиск.

## 0.1.11

- Окна поиска, перехода и редактирования получили скруглённые углы.

## 0.1.10

- Поиск перенесён из заголовка в окно, открываемое из футера или `Ctrl/Cmd+F`.
- Добавлены счётчик всех совпадений и переход на первый байт найденной
  последовательности.

## 0.1.9

- Убрана рамка фокуса вокруг всей таблицы.
- Исправлен конфликт `Cmd+F` с поиском VS Code.

## 0.1.8

- Результаты поиска и ошибки перенесены в футер.
- Добавлены команды Hex Editor: Find и Go to Address.

## 0.1.7

- Go to открывается по клику на Offset в футере.
- Переключатели Hex/Dec и `uint*_t` перенесены в футер.

## 0.1.6

- Расширение переименовано в Hex Editor.

## 0.1.5

- Добавлены направляющие линии при наведении.

## 0.1.4

- Добавлены представления Hex/Decimal и группировка `uint8_t`, `uint16_t`,
  `uint32_t`, `uint64_t`.
- Добавлено редактирование целых групп.

## 0.1.3

- Добавлен Data Inspector: целые числа, float, GUID, LEB128 и текстовые кодировки.
- Добавлен переключатель Little/Big Endian.

## 0.1.2

- Убран отдельный пункт Hex Editor из контекстного меню проводника.

## 0.1.1

- Исправлена виртуальная прокрутка и автоматическая коррекция позиции браузером.

## 0.1.0

- Первый выпуск: hex-таблица, ASCII, адреса, переход к адресу, поиск, выделение,
  редактирование байтов, сохранение, Undo/Redo и резервные копии.
