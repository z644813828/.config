# Multi Cursor (Atom-style)

Порт атомовского пакета [joseramonc/multi-cursor](https://github.com/joseramonc/multi-cursor)
для VS Code — то, чего нет во встроенном мультикурсоре.

## Клавиши

| Клавиши | Действие |
| --- | --- |
| `alt+j` | добавить курсор строкой ниже |
| `alt+k` | добавить курсор строкой выше |
| `alt+shift+h` | сдвинуть **последний** курсор влево |
| `alt+shift+j` | сдвинуть **последний** курсор вниз |
| `alt+shift+k` | сдвинуть **последний** курсор вверх |
| `alt+shift+l` | сдвинуть **последний** курсор вправо |

На macOS `alt` — это `option`.

Без раскладки, но доступны через палитру команд (и можно повесить свои клавиши):
`Multi Cursor: Expand All Up` / `Expand All Down` — курсоры до начала/конца файла.

## Чем отличается от встроенного

* **Обратное направление убирает курсор, а не добавляет.** У `alt+j`/`alt+k` есть
  понятие «последнего» курсора. Промахнулись на строку — жмёте обратную клавишу и
  лишний курсор исчезает. Встроенные `Add Cursor Above/Below` растут в обе стороны
  сразу, и снять лишний курсор ими нельзя.
* **Последний курсор двигается отдельно.** `alt+shift+h/j/k/l` двигают только его,
  остальные стоят на месте. Во встроенном мультикурсоре такого нет вообще: любая
  стрелка двигает все курсоры разом.
* Если у последнего курсора есть выделение, `alt+shift+*` его расширяет, а не
  сбрасывает.
* Наехали последним курсором на другой — они схлопываются в один.

Колонка запоминается: спуск через короткую строку не «съедает» позицию, на
следующей длинной строке курсор вернётся в исходную колонку. Табы считаются по
ширине табуляции редактора, а не как один символ.

## Установка

```
code --install-extension multi-cursor-1.0.0.vsix
```

Или в VS Code: `Extensions` → `…` → `Install from VSIX…`.

## Разработка

```
node test/run.js
```

Тесты гоняют логику на заглушке VS Code API — без запуска редактора.
