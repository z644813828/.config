# Changelog

## 1.2.0

Исправлен сброс последнего добавленного курсора на основной после общего
перемещения курсоров, если их количество не изменилось. При добавлении сверху
вниз последним остаётся нижний курсор, снизу вверх — верхний.

Щелчок мышью, смена редактора или изменение количества курсоров внешней командой
сбрасывают отслеживание на основной курсор.

## 1.1.0

Исправлен обратный порядок курсоров при расширении вниз, нарушавший соответствие
строк при `yy` → `p`. Последний курсор отслеживается отдельно от основного.

## 1.0.0

Первая версия: `alt+j`/`alt+k` для добавления курсоров и `alt+shift+h/j/k/l` для
перемещения последнего курсора, плюс `Expand All Up`/`Expand All Down`.
