# Host Terminal

Добавляет «Терминал хоста» в меню рядом с кнопкой «+» панели терминала.
Работает в локальном VS Code и при подключении к Dev Containers / Remote SSH.
Запускает системную оболочку пользователя в домашней папке компьютера,
на котором работает настольный VS Code. Для удалённого Docker это компьютер
клиента, а не сервер Docker. Профиль VS Code по умолчанию не используется.

Установка: в локальном окне VS Code откройте Extensions → … → Install from VSIX…
и выберите `host-terminal-0.1.0.vsix`. При необходимости выполните
Developer: Reload Window, затем подключитесь к контейнеру.
Расширение должно быть установлено локально, не внутри контейнера.

Реализация использует UI extension host и `cwd` с URI `file:`, чтобы VS Code
выбирал локальный backend терминала. Браузерный VS Code не поддерживается.
